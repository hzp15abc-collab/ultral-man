# 架构（候选，未冻结）

iPhone 摄像头 → 本地匿名姿态模型 → 标定与可达区 → 可信动作事件 → 游戏状态机 → 3D 角色/城市/怪兽/粒子 + 音频/提示 → iPhone Safari；iPad/电视是兼容目标。

候选资产制作与运行时引擎分离：Blender 或其他授权建模/现成资产方案 → 骨骼/材质/动画 → 移动端优化 → 运行时引擎（Three.js、Babylon.js 等为未验证示例）。需同场景比较实际识别+渲染、资源、时延、丢失恢复和许可。

输入管理负责相机权限和退出释放；推理只输出匿名短时姿态；控制层负责镜像/裁切/置信度/去重；规则层只接统一事件；渲染、音频订阅同一事件。跟踪丢失暂停或降级，触屏练习不等于体感通过。禁止上传或录制摄像头影像。具体接口、选型、性能预算在 G1c+D 后冻结。
