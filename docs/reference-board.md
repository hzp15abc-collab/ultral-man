| 方向 | 可见风格 | 可参考来源 |

2026-11-22 用户明确确认 **B 明亮动画特摄**，玩法沿 U0-03 不变；A 与混合方向不作为本轮审美目标。共同玩法原则仍为原创英雄守护城市、非接触轻松姿态触发柔和能量反馈、儿童能读懂的提示、成功反馈、暂停与静音；不频闪、不震屏惊吓、不采用破坏城市的目标。此确认仅为审美方向及既有玩法授权，不能声称用户已试玩或所有实际素材合格。

不保存未获许可的第三方原素材。B 已成为本轮审美方向基准，实际可见/可听成品与音频仍 UNVERIFIED；待 D3 冻结测试协议，不提前实验。
