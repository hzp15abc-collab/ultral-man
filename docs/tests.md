## G1b 协议（U1 已确认 · 独立 D3 冻结）

T1 Three.js + MoveNet，T2 Babylon.js + 同版 MoveNet，T3 同版 Three.js + MediaPipe；PlayCanvas 与 BlazePose 备选。D3 核定分组和协议后方可开始隔离资格预检，待预检锁定确切包/模型版本及 hash、许可证与同源资源白名单，审核一致后才实际运行。无法合法获得依赖/权重、实际许可证或无遥测证据不足则 UNVERIFIED/淘汰，不伪造安装结果。MediaPipe 精确锁版、模型许可与零遥测硬门不可放宽。

实验共用一份合法原创/CC0 GLB 文件，1 原创英雄、1 卡通怪兽、16 重复建筑模块；固定 960×540 内部画幅、同一横屏视口映射、同相机参数、同环境光+一个方向光、最多 32 同时粒子，种子 20261122；同一动画/事件语义、固定轮次。实际执行前锁定 GLB hash、输入样本 hash、版本、相机真实参数、设备/Safari 版本、固定配置、网络条件及测量方法并记工单。若需改配置，先提交 D 复核并对受影响三组重测；不事后降标。

三种工况分别记录：A 仅渲染、B 仅真实模型推理、C 同时运行（C 为核心性能验收）。用同一授权成人/合成样本与同一真机设备/位置/光照，正反例顺序以固定种子确定；仅本地短时处理、匿名事件统计，不录存儿童影像。注入坐标、触屏只能作逻辑测试；须实际模型处理视频/合成相机流，真机还须真实摄像头许可及用户操作。桌面或浏览器代理数据可筛查，不等于 iPhone。真实入口必须获用户授权的 HTTPS 地址，未授权不可变更 Pages 或其他仓库；无真实入口/真机时停待验。
