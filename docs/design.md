# 游戏设计（U0-03 范围）

玩家进入角色选择→3D 城市→引导校准/变身→卡通怪兽登场→简单非接触动作产生幻想能量→关卡完成→重玩/下一关。多角色、多怪兽和场景通过数据化模块扩充。左右自然挥手、双臂交叉、经典一横一竖光线姿势是候选控制；不鼓励出力、快挥或人与人接触。

儿童体验：直观动画/音频提示、短回合、成功反馈优先、可暂停、不频闪或惊吓、身体可达性与安全。视觉采用完整 3D 世界；相机预览形式待研究。角色/怪兽/城市场景应统一风格，合规资产或原创替代；具体画风、数量、动画、音乐、关卡难度等由真实参考板与 U1 共同冻结。所有审美验收必须看实际游戏事件、实际可听声音；不得凭源文件自评。
