# 游戏设计（U0-03 / U1 B · W3 REVIEWED）

玩家进入角色选择→3D 城市→引导校准/变身→卡通怪兽登场→简单非接触动作产生幻想能量→关卡完成→重玩/下一关。多角色、多怪兽和场景通过数据化模块扩充。左右自然挥手、双臂交叉、经典一横一竖光线姿势是候选控制；不鼓励出力、快挥或人与人接触。

儿童体验：直观动画/音频提示、短回合、成功反馈优先、可暂停、不频闪或惊吓、身体可达性与安全。视觉采用完整 3D 世界；相机预览形式待研究。所有审美验收必须看实际游戏事件、实际可听声音；不得凭源文件自评。

## U1 确认的 B 明亮动画特摄

2026-11-22 用户选择 B，既有玩法不变。原创流线英雄、巨大身形与城市建筑尺度对比、明亮柔和背景/轮廓光、能量环与色彩一致；怪兽外观卡通友善、非恐怖，游戏目标守护城市。使用原创造型、名称及合规资源，不复制官方标志/原模型/配乐。关卡关注成功与提示而非力量、速度或破坏，姿态仅用于触发幻想能量动画，不做真实动作训练。视觉与音频必须不频闪、不惊吓、无剧烈震屏、可独立调音和静音；横屏可读。具体数量、模型、配乐及最终表现待合规核权、实验选型及独立审美验收。
